# SeguCost – Especificación de Requerimientos de Software

Repositorio de evidencias del proyecto de medio término de **Ingeniería de Software I**
(ESPOL – FIEC), Equipo T4. Tutor académico: Dr. Carlos Mera.

## Descripción del proyecto

**SeguCost** es un sistema web y móvil de gestión productiva, control de tiempos y costeo
industrial para **SEGUPLAST S.A.**, empresa de Guayaquil que fabrica fundas plásticas.
Hoy la empresa anota los pedidos a mano en un block de órdenes y no registra de forma
sistemática los tiempos, las pausas ni las mermas de la planta.

SeguCost registra solicitudes, cotizaciones, pedidos confirmados, órdenes de producción,
mermas, tiempos y pausas, y calcula el costo estimado, el costo real y la rentabilidad.
Funciona junto a Dobra, el sistema actual de la empresa, sin reemplazarlo.

## Técnicas de levantamiento aplicadas

- Entrevista a la representante de la empresa (notas de voz).
- Cuestionario de seguimiento C2 (18 preguntas por WhatsApp).
- Análisis documental (CONOPS y acta de compromiso).
- Historias de usuario y mapa de historias.
- Prototipado en Figma.
- Validación con el cliente mediante acta de conformidad.
